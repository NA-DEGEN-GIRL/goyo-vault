고요 금고 · Goyo Vault 0.5.2

1. ZIP 전체를 나만 쓰고 동기화되지 않는 폴더(예: C:\Users\내이름\GoyoVault)에 푸세요.
   ZIP 안·임시 폴더, OneDrive가 백업하는 문서·바탕 화면, C:\ 바로 아래는 피하세요.
   실행 전에 PowerShell의 Get-FileHash로 ZIP의 SHA-256이 릴리스 설명과 같은지 확인하세요.
2. goyo-vault.exe를 실행하고 '새 금고 만들기'를 누르세요.
   (서명되지 않은 프로그램이라 SmartScreen 경고가 나오면 '추가 정보 → 실행')
3. 서로 관계없는 단어 4~6개로 된 긴 비밀번호를 정하세요. dragon·sunshine처럼 흔한
   비밀번호 목록에 있는 단어는 빼고 고르세요.
4. 휴대폰 OTP는 기본 꺼짐이지만 켜 두기를 권장합니다. 켜면 비밀번호가 새어도 휴대폰
   없이는 이 앱으로 열 수 없습니다. 파일을 복사해 간 사람은 막지 못하고, 휴대폰을 잃으면
   OTP 백업 없이는 열 수 없습니다.
   켜려면 'OTP 켜기'를 누르고 휴대폰 Google Authenticator에서 + → QR 코드 스캔으로
   등록한 뒤 6자리 번호로 확인하세요. 나중에 켜거나 끌 수는 없습니다.
   (OTP 앱 안의 스캐너로만 찍고 사진으로 남기지 마세요.
    스캔이 안 되면 + → 설정 키 입력 → 시간 기준으로 화면의 키를 입력.
    휴대폰 분실 대비: 금고를 연 뒤 아래 'OTP 백업'으로 예비 기기에도 등록하세요.)
5. 처음에는 가짜 값으로 항목 저장 → 금고 백업 → 열쇠 백업 → 복원을 시험하세요.

필요 환경: Windows 11 x64, CPU RDSEED 지원.
첫 실행의 기본 파일은 프로그램 옆 vault.goyo와 vault.goyokey입니다.
업데이트: 새 ZIP을 같은 곳에 덮어써서 풀면 GoyoVault 폴더의 금고·열쇠 파일은 그대로 남습니다.
두 파일과 비밀번호(OTP를 켰다면 휴대폰 OTP도)가 필요합니다. 분실 우회 복구는 없습니다.
0.5.0부터 OTP 없이 만든 금고는 0.4.x 이하 버전에서 열리지 않습니다.
가장 중요: 열쇠 파일은 금고와 다른 곳(USB 등)에 두세요. 같은 폴더면 폴더째 가져간
사람은 OTP와 관계없이 비밀번호만 추측하면 됩니다. 앱이 빨간 글씨로 경고합니다.
자동 백업은 없습니다. 직접 하세요:
  - 금고 백업: 항목을 추가·수정할 때마다 (특히 새 니모닉)
  - 열쇠 백업: 금고를 만든 직후 한 번, 비밀번호를 바꿀 때마다
  - OTP 백업: OTP를 켰다면 금고를 만든 직후 한 번 (예비 휴대폰이나 종이)
  - 비밀번호: 앱 안에 복구 수단이 없으니 따로 기억·보관
금고 백업과 열쇠 백업은 서로 다른 저장장치에 두고, 가끔 실제로 복원해 보세요.

열린 금고는 다른 앱에 30초 넘게 머무르면 자동으로 잠깁니다.
전환하는 순간 보이던 비밀값과 복사 허용은 바로 가려집니다.
새 금고 만들기·복원 화면은 전환해도 입력 내용이 남습니다(미사용 5분/60초 후 삭제).
편집 중 다른 앱에서 값을 복사해 왔다면 30초 안에 붙여넣으세요.
비밀정보·메모 칸의 한글 IME는 차단됩니다. 한글은 붙여넣기로 입력하세요.
다른 칸도 입력기에 따라 한글 직접 입력이 제한되면 붙여넣기를 사용하세요.
금고의 값을 복사하려면 '복사 허용'을 먼저 켜야 합니다.
복사한 값은 15초 뒤 지우기를 시도합니다.
비밀번호를 바꿔도 이전 열쇠 사본의 효력이 없어지는 것은 아닙니다.

개발 버전입니다. AI 검토와 자동 테스트를 받았지만 전문 보안 감사 제품은 아닙니다.
감염된 Windows에서 안전함을 보장하거나 모든 캡처를 막을 수는 없습니다.
