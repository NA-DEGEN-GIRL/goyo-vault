# Security policy · 보안 취약점 신고

Goyo Vault is a development release that has not had a professional security audit. Reports are welcome.

- **Report privately** through GitHub: *Security → Report a vulnerability* on this repository. Please do not open a public issue for a vulnerability.
- Include the version (`goyo-vault.exe` properties or the release name), Windows version, steps to reproduce and the impact you expect. Never send real vault files, key files, passwords or OTP codes; synthetic ones are enough.
- Only the latest release is fixed. Older releases are not patched.

고요 금고는 전문 보안 감사를 받지 않은 개발 버전입니다. 취약점은 이 저장소의 **Security → Report a vulnerability**로 비공개 신고해 주세요. 공개 이슈로 올리지 마세요. 버전, Windows 버전, 재현 방법과 예상 영향을 적어 주시고, 실제 금고·열쇠 파일·비밀번호·OTP는 절대 보내지 마세요. 가짜 값으로 충분합니다. 최신 릴리스만 수정합니다.
