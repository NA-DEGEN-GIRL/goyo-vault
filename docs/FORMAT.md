# Goyo v1 파일 형식

수치는 별도 표기 없으면 little endian. 사용자 지정 KDF 비용은 받지 않아 악성 헤더의 메모리/CPU 비용 확대를 막습니다. 최대 금고 파일 8 MiB, 항목 1000개, 이름 256바이트, 종류 64바이트, 비밀·메모 각각 UTF-8 8192바이트. NUL 및 불완전 UTF-8은 거부합니다.

## 열쇠 파일: 정확히 148바이트

|위치|길이|내용|
|---|---:|---|
|0|8|`GOYOKE01`|
|8|16|무작위 금고 ID|
|24|32|무작위 Argon2 salt|
|56|24|무작위 XChaCha nonce|
|80|68|52바이트 암호문 + 16바이트 태그|

AAD는 앞의 80바이트 전체. 암호화 키는 Argon2id v0x13(password, salt), m=262144 KiB, t=3, p=1, 출력 32바이트. 평문은 데이터 키 32바이트 + TOTP 비밀키 20바이트입니다. 파일명·디스크 경로는 암호화 키에 포함하지 않아 USB 이동과 다른 PC 복원이 가능합니다.

## 금고/백업 파일

|위치|길이|내용|
|---|---:|---|
|0|8|`GOYOVA01`|
|8|16|대응 열쇠의 금고 ID|
|24|24|매 저장마다 새 무작위 nonce|
|48|가변|암호문 및 16바이트 태그|

AAD는 앞의 48바이트 전체. 키는 열쇠 파일에서 복호화한 데이터 키입니다. 평문은 마지막 승인 OTP step(u64), 항목 수(u32), 각 항목의 이름/종류/비밀/메모 순서이며 각 문자열은 u32 바이트 길이 + UTF-8입니다. 후행 데이터는 거부합니다. 세션 잠금 해제 시 OTP step을 먼저 저장한 후 항목을 노출합니다.

OTP는 RFC 6238 HMAC-SHA1, 6자리, 30초, 현재 step ±1 범위이며 저장된 마지막 step보다 커야 합니다. SHA-1은 Google Authenticator 상호운용을 위한 HMAC 용도로만 사용합니다. 인증 태그·암호화에는 SHA-1을 사용하지 않습니다.

파일 매직·ID·salt·nonce·암호문 길이는 공개 정보입니다. 파일 길이와 파일 존재 여부를 숨기지 않습니다. 모든 문자열과 OTP 비밀키, 데이터 키는 디스크에서 암호화됩니다.
