# 보안 키 (실험 기능)

<b>한국어</b> · [English](SECURITY_KEY.en.md)

> [!WARNING]
> **실험 기능: 실제 보안 키로 검증하지 않았습니다. 기본 빌드와 릴리스 ZIP에는 들어 있지 않습니다.**

고요 금고 0.9.0에는 열쇠 파일을 비밀번호와 보안 키(YubiKey 등 FIDO2) 둘 다로 잠그는 선택 기능이 만들어지고 있습니다. 이 기능은 보안 키 기능을 넣어 직접 빌드한 고요 금고에만 들어갑니다. 켜는 법, 여러 키 등록, 키를 잃었을 때 할 일은 기능이 완성될 때 이 문서에 씁니다.

**기본 빌드가 보안 키 열쇠 파일을 만나면.** 릴리스 ZIP의 `goyo-vault.exe`는 보안 키로 잠긴 열쇠 파일(첫 8바이트가 `GOYOKH`나 `GOYOKS`로 시작하는 파일)을 열지 않습니다. 파일을 고르는 순간에, 그리고 '열기'나 '복원'을 누르면 비밀번호를 확인하기 전에 첫 8바이트만 보고 "이 열쇠 파일은 보안 키(YubiKey 등)가 있어야 열립니다…"라고 알립니다. 비밀번호가 틀렸다고 하지 않고, 실패로 세지 않으며, 다시 시도 대기 시간도 없습니다. 파일이 잘렸거나 더 새로운 버전에서 만들어 형식 검사를 통과하지 못하면 "파일이 손상되었거나 더 새로운 버전에서 만든 파일일 수도 있습니다."를 덧붙입니다. 기본 빌드는 그런 파일이 손상된 것인지 판단할 수 없으므로, 저장이 끊기며 남은 임시 파일(`.goyotmp`)로 바꿔 넣지도 않습니다. 보안 키 열쇠 파일로 저장된 금고 파일을 그 열쇠가 없는 열쇠 파일로 열면 "이 금고 파일은 보안 키로 잠긴 열쇠 파일로 저장되었습니다…"라고 알리고 열지 않습니다. 이런 파일을 열려면 보안 키 기능이 든 빌드가 필요합니다.
